# MMAT105 Genel Matematik

MYO/ SMYO/ DGS/ Lise / TYT düzeyinde, teorisi az, örnek ağırlıklı 15 haftalık ders materyali (2026–2027 Güz). Her örnekte önce soru, sonra çözüm gelir.

## Haftalık plan

| Hafta | Konu |
|---|---|
| 01 | Temel kavramlar, işlem önceliği, ardışık sayılar, faktöriyel |
| 02 | Asal sayılar, asal çarpanlara ayırma, tam bölenler, bölme |
| 03 | Bölünebilme kuralları, EBOB ve EKOK |
| 04 | Rasyonel ve ondalık sayılar |
| 05 | Birinci dereceden bir bilinmeyenli denklemler |
| 06 | Birinci dereceden iki bilinmeyenli denklemler |
| 07 | Basit eşitsizlikler ve mutlak değer |
| 08 | Deneme sınavı ve çözümleri |
| 09 | Üslü sayılar |
| 10 | Köklü sayılar |
| 11 | Çarpanlara ayırma ve özdeşlikler |
| 12 | Oran, orantı, ortalamalar |
| 13 | Sayı, kesir ve yaş problemleri |
| 14 | Yüzde, kâr–zarar, karışım ve faiz problemleri |
| 15 | Deneme sınavı ve çözümleri |
